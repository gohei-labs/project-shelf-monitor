Citable rule codes

This review asks for approval to give every rule a stable NIST-style identifier (category code + sequence) and nest the monitor by category.

Requested Approval

  1. Every rule gets a code (FILE-01, WA-02, …): category prefix + two-digit sequence, stable once assigned (never renumbered or reused), validated by the registry gate for format, prefix match, and uniqueness. The kebab-case id stays the machine key for gates.
  2. The monitor nests rules under category subheadings inside the two enforcement groups; the card's left tag is the code — matching the identifier-first style of the project's other lists.
  3. Category code prefixes: FILE / SEC / ENV / GOV / DOC / PORTAL / APP / REV / CTX / DEC / WA.
