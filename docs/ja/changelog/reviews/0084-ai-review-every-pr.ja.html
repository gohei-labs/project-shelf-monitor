全プルリクエストに AI レビュー

このレビューは、全てのプルリクエストに AI レビュー記録を必須とし、docs のみの除外を廃止する承認を求めるものです — 分類ルールを単純ルールに置き換えます。

Requested Approval

  1. 単純ルールの採用。コード・governance データ・ドキュメントを問わず、全ての PR が新鮮な AI レビュー記録（現在の head・明示的な所見・異なる作成者/レビュアーコンテキスト）を持つ。記録ゲートは「この PR にレビューが要るか」を判定せず、記録の検証だけを行う。
  2. docs のみの除外を廃止。DEC-01 のルール文・プロトコル文書・ゲートの全てから除外を撤去。パス分類（変更 0074 の governance データ一覧を含む）は報告用として維持。
  3. コストの受け入れ。誤字修正の PR でも独立レビュー1回分を払う。対象範囲の問いが2度続き、分類ルールが実運用で意外だと分かった上での、オーナーの明示的な選択。

Risk

低・厳格化のみ — 緩める要件は無い。運用上の注意: CI が PR を評価する時点で記録が存在する必要があるため、実務は PR 作成時に本文へ記録を入れる（push 後コメントの既知のタイミング失敗を回避）。両方向で確認済み: docs のみの変更は従来「記録不要」（exit 0）で通過したが、いまは記録なしで失敗（exit 1）。実装パスの挙動は従来どおり。

Not Decided Here

  • 些細な PR のレビューを浅い深度で行ってよいか — 記録の形式は不変。深度はプロトコル内の裁量のまま。
  • push 後に投稿された記録の CI タイミング改善（保留。作成時に本文へ入れれば回避可能）。
  • 報告用分類への governance データ追加（0074 の保守ルールを継続）。
