全ルールに「防ぎたいこと」を明記

このレビューは、全 38 ルールに必須の「防ぎたいこと（prevents）」を追加し、モニターでルール文より先に表示する承認を求めるものです — カードが手段だけでなく目的を語るようにします。

Requested Approval

  1. フィールドの採用。レジストリの全ルールが二言語の prevents — 防ごうとしている具体的な失敗の平易な記述 — を持ちます（レジストリ schemaVersion 3→4）。ゲート（GOV-02）はフィールドや片方の言語が欠けたルールを拒否し、ジェネレータも描画を拒否します — 仕組みが「なぜ」抜きで表示されることはなくなります。
  2. 表示の採用。カード一覧では各タイトルの下に prevents の行を表示。詳細パネルは「防ぎたいこと」ラベル付きブロックを先頭に、その後にラベル付きルール文。例（発端になった ENV-03）: 従来 —「コンポーネントのディレクトリ追加前に stack と check command を宣言する」。今後はカードがまず「検証方法が不明な野良コードの混入 — フォルダ名からスタックを推測した勝手な実装」と述べます。
  3. 38 件の文言の承認。全 38 ルール分の prevents（英日）を本変更で執筆しました。各ルールの note・変更履歴・ゲートの挙動から要約した編集判断であり、以後の PR でスキーマ変更なしに文言を磨けます。
