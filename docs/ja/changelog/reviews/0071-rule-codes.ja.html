引用可能なルールコード

このレビューは 全ルールに NIST 式の安定した識別子（カテゴリ略号＋連番）を与え、モニタをカテゴリで入れ子表示にすること の承認を求めます。

承認をお願いする事項

  1. 全ルールに code（FILE-01、WA-02 など）を付与：カテゴリ略号＋2 桁連番。一度割り当てたら安定（改番・再利用しない）。registry ゲートが形式・接頭辞一致・一意性を検証。kebab-case の id はゲート用の機械キーとして継続。
  2. モニタは 2 つの強制グループの中でカテゴリ小見出しの下にルールを入れ子表示。カード左端のタグはコード — 識別子を先頭に置く本プロジェクトの他の一覧と揃う。
  3. カテゴリ略号：FILE / SEC / ENV / GOV / DOC / PORTAL / APP / REV / CTX / DEC / WA。

リスク

追加のみのスキーマ変更：ゲート挙動は不変。id も不変のため、id 参照はどこも動かない。安定性ルール（改番禁止）はここから始まり、それが守るべき主要な規律。

ここでは決めないこと

  • モニタのファイル名／URL の改名（先送りのまま）。
  • ルール名・散文の旧語彙の掃討（例：レビュー成果物とレビュー資料の併存）— 別途のオーナー判断。
