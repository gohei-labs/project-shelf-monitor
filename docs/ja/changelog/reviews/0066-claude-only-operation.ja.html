Claude 単独運用

このレビューは Codex / Gemini 固有の規約とアダプタファイルを撤去し、Claude Code を本プロジェクト唯一の運用エージェントとすること の承認を求めます。

承認をお願いする事項

  1. 未使用のルートアダプタ入口 AGENTS.md（Codex 用）と GEMINI.md（Gemini 用）を削除する。ルートアダプタは CLAUDE.md のみとし、新しいアダプタは別ツールを実際に採用したときにのみ追加する。
  2. レビュールールをエージェント中立の用語に改める：code-review standards と AI review protocol の「Codex review-only pass」を「AI review-only pass」に置き換える。記録の見出しは「AI Review Record」のままとし、過去の PR 記録を有効に保つため旧「Codex Review Record」見出しも引き続き受理する。
  3. 推奨ブランチ名の接頭辞を codex/* から claude/* に変更する。作業しているエージェントは Codex ではなく Claude であるため（PR #87 でのオーナー指摘）。

リスク

ドキュメントのみの変更で、ゲートスクリプトや CI の挙動は変わらない。主なリスクは用語のずれ：履歴（変更記録・過去のレビュー記録・マージ済みブランチ）には旧 Codex 表記が残り、記録ゲートは旧見出しを意図的に受理し続ける。緩和策：ルール文書に旧見出し受理を明記し、履歴の表記を変えない理由を本資料に記録する。

ここでは決めないこと

  • 過去の記録の Codex 表記は維持する：変更記録、過去のレビュー資料、git 履歴、一時停止中ルール LLM-GR-006 の「Codex 同梱ランタイム」への言及。
  • scripts/guardrails/check-ai-review-record.ps1 は旧「Codex Review Record」見出しを引き続き受理する。受理の廃止はここでは提案しない。
  • agent-policy.md と build-agent-config.ps1 の他ハーネスへの説明的言及は残す：生成設定が Claude ハーネスのみである事実を正確に述べているため。
  • CodeRabbit 評価メモ内の外部製品としての Codex への言及は残す：本プロジェクトの構成ではなく、サードパーティ製品の能力の説明であるため。
  • 将来別の AI エージェントを採用するかどうかは別の意思決定とする。
