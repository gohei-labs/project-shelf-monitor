Enforce independent-context AI review

This review asks for approval to make self-review — the author context approving its own code — impossible at the audit-record level. Part 2 of the quality-gate trilogy (#81).

Requested Approval

  1. Build the independence requirement into the record format. The same AI Review Record section must declare both Author context: (the identifier of the context that wrote the change) and Reviewer context: (the review-only context), and the gate enforces that they differ. The check runs on the record that passed the freshness check (head-commit match), so independence cannot be borrowed from an older record.
  2. Approve the honest positioning. Declared identities are structured attestation, not cryptographic proof. But a violation now requires an explicit false statement in a durable audit record — accidental or creeping self-review becomes structurally impossible.
  3. Formalize a practice already proven live. This format was exercised on PR #84: a fresh-context agent separate from the implementation session ran four adversarial review passes, found 11 issues (including two P1s), and every fix became a committed test case. This PR itself was reviewed by yet another fresh reviewer.

Risk

Attestation limits. A malicious agent could technically write a fake Reviewer context. The control's value is eliminating accident and drift (casual self-review becomes structurally impossible) and making violations visible (faking requires an explicit false statement in the audit record). Cryptographic identity proof was judged disproportionate for this repository and the limit is documented honestly.

Operating cost. Every implementation PR now requires an actual independent review (2-6 minutes per pass, per the #84 experience). This is the intended cost — it is the point of the trilogy.

Not Decided Here

  • Deterministic required-reading enforcement — part 3, #80.
  • Technical verification of reviewer identifiers (session-ID cross-checks).
  • Automated assessment of review quality or depth.
